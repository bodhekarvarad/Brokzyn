# 📈 Brokzyn - Full Stack Trading Dashboard



Brokzyn is a modern full-stack trading dashboard built using the MERN stack. It provides real-time market data visualization, portfolio tracking, and watchlist management through a responsive and intuitive user interface inspired by professional trading platforms like Zerodha.



---



## 🚀 Features



### 📊 Trading Dashboard



* Real-time market data visualization

* Interactive charts and analytics

* Clean and responsive trading interface



### 📈 Portfolio Management



* Track investments and holdings

* Monitor portfolio performance

* Manage multiple assets efficiently



### ⭐ Watchlist



* Add and manage favorite stocks

* Quick access to market updates

* Personalized tracking experience



### 🎨 Modern UI/UX



* Built with Material UI

* Fully responsive design

* Optimized for desktop and mobile devices



### ⚡ Performance Optimized



* Efficient API handling

* Fast data rendering

* Scalable architecture

## ⚙️ Installation & Setup



### 1️⃣ Clone the Repository



```bash

git clone https://github.com/bodhekarvarad/Brokzyn.git

cd Brokzyn

```



---



### 2️⃣ Backend Setup



```bash

cd backend

npm install

npm run dev

```



Backend server will start on:



```bash

http://localhost:5000

```



---



### 3️⃣ Frontend Setup



```bash

cd frontend

npm install

npm start

```



Frontend application will start on:



```bash

http://localhost:3000

```



---



### 4️⃣ Dashboard Setup



```bash

cd dashboard

npm install

npm start

```



Dashboard will be available at:



```bash

http://localhost:3001

```



---



## 🔑 Environment Variables



Create a `.env` file inside the `backend` directory:



```env

MONGO_URI=your_mongodb_connection_string

PORT=5000

```



Example:



```env

MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/brokzyn

PORT=5000

```
